# FlatMate

FlatMate — веб-сервис для поиска и аренды жилья с возможностью
размещения объявлений собственниками.

## Технологии

- Go — backend
- PostgreSQL — база данных
- REST API — взаимодействие с клиентом
- JWT — аутентификация
- bcrypt — хеширование паролей

## Реализованная функциональность

- Регистрация пользователей с ролями tenant и owner
- Вход в аккаунт по email и паролю
- Выдача JWT-токенов
- Проверка JWT и разграничение прав доступа
- Создание объявлений собственниками
- Привязка объявлений к собственникам
- Поиск квартир по бюджету и минимальной площади

## API

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | /register | Регистрация пользователя |
| POST | /login | Вход и получение JWT |
| POST | /flats | Создание квартиры (только owner) |
| GET | /flats/search?user_id=2 | Поиск квартир |

## Запуск проекта

Необходимы Go и PostgreSQL.

Перед запуском нужно создать базу данных и настроить
переменные окружения:

```bash
export DATABASE_URL="postgres://flatmate_app:YOUR_PASSWORD@localhost:5432/flatmate"
export JWT_SECRET="YOUR_RANDOM_SECRET"
```

Запуск сервера:

```bash
go run .
```

API доступен по адресу:

http://localhost:8080
